# Data-Science-Training
## Curriculum Summary

Completed a comprehensive hands-on Data Science training program covering Python programming, statistics, machine learning, SQL, model evaluation, feature engineering, clustering, time series analysis, and model deployment.

### Key Areas Covered

* **Python for Data Science**
  Data structures, functions, loops, NumPy, Pandas, data cleaning, missing value handling, and visualization with Matplotlib.

* **Data Visualization & Statistics**
  Exploratory data analysis, probability distributions, correlation analysis, hypothesis testing, and statistical interpretation.

* **Machine Learning Fundamentals**
  Supervised vs. unsupervised learning, regression and classification models, train/test splitting, and evaluation metrics such as RMSE and accuracy.

* **SQL for Data Analysis**
  Database querying, joins, aggregation, subqueries, and integration of SQL with Python workflows.

* **Decision Trees & Ensemble Learning**
  Random Forests, feature importance, cross-validation, and overfitting prevention techniques.

* **Classification & Model Evaluation**
  KNN classification, ROC/F1 metrics, precision-recall tradeoffs, and handling imbalanced datasets using techniques like SMOTE.

* **Feature Engineering & Hyperparameter Tuning**
  Scikit-learn pipelines, GridSearchCV, RandomizedSearchCV, and model optimization strategies.

* **Unsupervised Learning**
  K-Means clustering, hierarchical clustering, PCA, and customer segmentation techniques.

* **Time Series Analysis**
  Trend and seasonality analysis, lag features, rolling statistics, and introductory ARIMA forecasting.

* **Model Deployment**
  Model serialization, Streamlit dashboard development, and local deployment of machine learning applications.

* **Model Explainability & AI Ethics**
  SHAP/LIME interpretability, fairness in AI systems, and ethical considerations in predictive modeling.

* **Capstone Development**
  End-to-end portfolio project development including notebook documentation, README writing, visualizations, and optional Streamlit deployment.
